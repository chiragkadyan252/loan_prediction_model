About Loan Approval Prediction

A Machine Learning based loan approval prediction system.

Project Overview

This project is a Machine Learning based web application developed to predict whether a loan application is likely to be approved or rejected.

The application collects applicant financial and personal information through a Django web interface and sends the information to a trained Machine Learning model for prediction.

🐍

Python

Used as the primary programming language for the Machine Learning and web application.

🌐

Django

Used to develop the web application, authentication system and database integration.

🤖

Scikit-Learn

Used for the trained Machine Learning loan approval prediction model.

Machine Learning Model

The model uses applicant information to predict the loan approval status.

  • No. of Dependents
  • Education
  • Self Employed
  • Annual Income
  • Loan Amount
  • Loan Term
  • CIBIL Score
  • Residential Assets Value
  • Commercial Assets Value
  • Luxury Assets Value
  • Bank Asset Value
